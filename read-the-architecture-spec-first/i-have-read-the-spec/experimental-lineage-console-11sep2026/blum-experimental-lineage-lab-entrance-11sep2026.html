BLUM / EXPERIMENTAL LINEAGE LAB

A lineage-first laboratory for developmental experiments: design controlled genealogies, execute or reconstruct them, navigate corpora, compare historical witnesses, and measure declared output surfaces without losing provenance.

01 · Design

Lineage Console

Build trunks, forks and probe assignments; declare XML analysis streams; inspect design geometry; freeze an immutable manifest.
02 · Rehearse

Vertical Slice

Run the provider-agnostic orchestration against deterministic mocks. Proves ancestry, projections and sibling divergence without spending a token.
03 · Import

DAE Retrospective Workbench

Drop historical raw-call JSON locally. Verify ancestry from archived sent prefixes, preserve truncation/XML scars, and reconstruct exact or exploratory contrasts.
04 · Explore

Corpus + Battery Workbench

Navigate lineage, battery coverage and anomalies. Build versioned reusable probe batteries, save subsets, freeze them, and attach them to branches by fingerprint.
05 · Compare

Item History Wall

Select N4, A1 or another probe and read every indexed historical answer side by side. Switch between canonical item lineage and exact prompt wording, then filter by collection, condition, fork and XML surface.
06 · Analyze

Output Analysis

Select two historical observations and dissect the same declared output surface. The first instrument is deterministic Lexical Autopsy with explicit vocabulary ablation; later analyzers plug into the same boundary.
